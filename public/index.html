Box A–E Role Access Matrix

  • Box A (Records Staff): Only Records Section account can encode new Incoming documents and edit Box A.
  • Box B (RD / RD's Secretary): Only RD Secretary account can enter RD instructions and Time Frame of Action.
  • Box C (ARD / ARD's Secretary): Only ARD Secretary account assigns the responsible Division Chief via ARD's Instruction To.
  • Box D (Division Chief Action): Only the assigned Division Chief (e.g., STO, LTS, LEGAL, ARBDSP, RARAD/DARAB, or STO section) can fill Action Taken.
  • Box E (Records Dispatch & Return): Only Records Section account records final dispatch & return receipt.
  • Issuance & Mailing Process: Only Records Section & System Admin can encode, edit, delete, or sync entries; RD Office, ARD Office, and Division / Unit Chiefs have View-Only access.
  • Automated Tracking Status: Automatically computed from Box A → B → C → D → E without manual override.
